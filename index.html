The problem

During an incident, developers need to understand which services are failing, which errors repeat, and which requests are unusually slow. Sentinel organizes these signals into a structured report with supporting evidence and suggested investigation steps.

Core capabilities

Error analysis

Identify service error rates and HTTP 5xx failures.

Latency insights

Calculate p50/p95 latency and flag unusual observations.

Repeated signatures

Group recurring error messages to help narrow investigations.

Evidence-backed reports

Review findings, severity, confidence, and suggested next steps.

Python API and CLI

Use the command-line workflow or integrate through FastAPI.

Local-first design

Designed for local analysis without a paid AI API key.

Built with

Python 3.11+ · FastAPI · Pydantic · SQLite · pytest · Docker · GitHub Actions

Clone the repository and follow the README to install Sentinel and analyze the included sample events.
